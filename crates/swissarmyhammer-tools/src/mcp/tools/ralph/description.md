Stores instructions as `.ralph/<session_id>.md` with `set ralph`, recording the writing process as the owner. Used by Stop hooks to prevent Claude from stopping while work remains. When a Stop hook fires and this session owns an active instruction, `check ralph` returns `"decision": "block"` — the hook runs in a separate process whose session id never matches the setter's, so a miss on the named session falls back to the instruction whose owner process belongs to this session's process tree. An instruction owned by a live peer session, or by a process that has ended, never blocks. Call `clear ralph` when work is done to release the block; without an explicit `session_id` it removes the caller's own instruction, or, when there is none, only the instructions of sessions that have ended.
